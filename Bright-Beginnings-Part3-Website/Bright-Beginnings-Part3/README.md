# Bright Beginnings Learning Foundation — Part 3

A responsive multi-page website project for Bright Beginnings Learning Foundation.

## Pages
- `index.html` — homepage
- `about.html` — foundation background, mission and vision
- `programmes.html` — programme cards, search and grade filter
- `volunteer.html` — volunteer interest form
- `enrolment.html` — learner enrolment request
- `enquiry.html` — service, volunteer and sponsorship enquiries
- `donate.html` — support information
- `contact.html` — contact form and Lebowakgomo area map

## Technologies
HTML5, CSS3, JavaScript, Netlify Forms, Google Maps embed, GitHub and Netlify.

## Before publishing
1. Add your own image files to `images/` using the filenames referenced by the HTML.
2. Replace `REPLACE-WITH-VERIFIED-EMAIL@example.com` in `script.js` with the organisation's real email address.
3. Replace `YOUR-NETLIFY-SITE` in `robots.txt` and `sitemap.xml` with the actual Netlify site name.
4. Verify all programme times, contact details and organisational information before publishing.
5. Deploy the whole folder to Netlify. Netlify detects the forms after deployment; check the Forms section and enable form detection if prompted, then redeploy if necessary.

## Forms
The volunteer, enrolment and enquiry forms use Netlify Forms. They require deployment to Netlify to receive submissions. Test each form after deployment in the Netlify dashboard.
The contact form uses `mailto:`. It opens the visitor's email application with a prepared message; it does not send automatically.

## Testing checklist
- Open every HTML page and test all navigation links.
- Test the mobile menu at narrow screen widths.
- Search and filter programmes.
- Open and close gallery images using the mouse, close button and Escape key.
- Test required fields and invalid email/phone values.
- Deploy to Netlify and test Netlify form submissions.
- Check the contact email recipient and sitemap domain before publishing.

## Important project notes
The map indicates the general Lebowakgomo area, not a confirmed street address. No bank account details or actual contact information are invented in this project. The programme timetable is labelled as an example and must be verified before being presented as a confirmed schedule.
